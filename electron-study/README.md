# MyCut — Electron / React UI study

Отдельный рабочий экран для сравнения со стартовым Rust/egui UI. **Не миграция редактора и не полноценная копия Unreal.** Никакие файлы проектов не открываются и не изменяются.

Стек: Electron 44.8.0, React/React DOM 19.3.1, HTML/CSS, esbuild. Node.js >=22.12, pnpm; версии и дерево закреплены в `pnpm-lock.yaml`.

```sh
pnpm install
node node_modules/electron/install.js
pnpm start
```

Electron этой версии устанавливает runtime отдельной командой. На Windows также можно запустить `../Start-MyCut-Electron.cmd`, после установки зависимостей. macOS/Linux: те же команды pnpm; нужны совместимые ОС и системные библиотеки Electron. На них прототип пока не проверялся. Установщики/подпись приложений не настроены.

## Что работает

### Переименование в строке

Rename в меню и F2 открывают поле **на месте названия строки Outliner**, с выделением исходного текста. Enter/потеря фокуса подтверждают; Escape отменяет; пустое имя по Enter оставляет поле для исправления. При клике снаружи пустое имя отменяется. Перенос строки временно отключён, чтобы можно было выделять текст. Реальное изменение даёт одну Undo/Redo-запись; имя без изменений не создаёт историю. Идентификатор, выделение, порядок, родитель и трансформация сохраняются. Папки переименовываются так же. Существующая защита закрепления/множественного выделения сохранена. Диалог NameDialog теперь используется только для создания/группировки папок, не Rename.

У контекстного меню полностью убрана шапка с названием слоя/количеством выделенных: меню начинается с заголовка группы команд. Возле Rename показана F2. Сборка, 28 unit-тестов и пять Electron UI-сценариев; отдельный сценарий Rename проверяет Enter/Escape/blur/F2, отсутствие модального окна и шапки, Undo/Redo и ограничения. Снимок: `test-results/inline-rename/inline-rename-editing.png`.

### Контекстное меню: приоритеты и группы

`src/menu-model.mjs` группирует дескрипторы команд по назначению и явному priority. Для выбранного объекта идут Object (Edit properties, Rename), Hierarchy (Move to new folder), Create (новый слой, папка), Manage (Delete). На пустом месте/корне Create становится первым. Удаление всегда отдельно внизу; недоступные пункты не скрываются. Заголовки блоков и тонкие линии разделяют группы, слева у команд собственные векторные иконки из общего Icon, без ассетов Epic. Функции Unreal вроде revision control/force load не добавлены, поскольку соответствующей функциональности в MyCut нет.

Сборка и 25 unit-тестов прошли. Outliner UI-сценарий дополнен проверками порядка групп, иконок всех команд, ArrowDown/End и удержания меню в границах окна. Снимок: `test-results/grouped-menu/outliner-context.png`.

### Outliner по схеме пользователя

Общий React-компонент выделен в `src/outliner.jsx`, операции иерархии — `src/hierarchy.mjs`. Старой параллельной реализации Outliner в `app.jsx` больше нет. Это развитие Electron-прототипа, не перенос обратно в Rust.

- Shift выделяет диапазон видимых строк; Ctrl/Cmd добавляет/убирает отдельные объекты. Обычный клик оставляет один. ПКМ по выбранной строке сохраняет групповое выделение, по другой — выбирает её.
- Контекстное меню для строки/группы/пустого места/корня: Edit properties, Rename, Delete, Move to new folder, Create folder, Create new layer. Недоступные действия остаются видимыми и disabled. Меню закрывается снаружи/Escape, поддерживает стрелки/Home/End/Enter. На пустом месте и корне доступны только создания.
- Закреплённые слои нельзя перетаскивать, удалять или группировать. Папку с закреплённым потомком также нельзя переносить/удалять в обход защиты; проверки дублируются в чистой модели. В группе с закреплённым слоем групповое изменение запрещено целиком.
- Folder — реальный узел с parentId; сворачивается, имеет вложенные слои/папки, поиск оставляет видимыми предков. Перенос в середину строки папки меняет родителя; края строки переставляют до/после. Циклы запрещены. Перенос папки включает потомков, групповой перенос сохраняет относительный порядок. Невозможная вставка не подсвечивается.
- Родительское скрытие/закрепление действует на потомков. Папки сами не рисуют пиксели; координаты/масштаб детей при группировке не меняются. Порядок холста обходится по иерархии. Каждая операция создания/переименования/группировки/удаления/переноса — одна Undo-транзакция.
- Разделитель под Outliner изменяет соотношение высот Outliner/Details, не сцену. Можно тянуть мышью или использовать стрелки при фокусе разделителя; Reset workspace возвращает исходное положение.

Новый Layer пока прозрачный пустой узел: рисование пикселей ещё не подключено. Множественное выделение даёт групповые операции Outliner, **не** общий манипулятор трансформации: Details явно показывает количество выбранных объектов. Папки пока организационные, не Prefab/эффекты/маски и не изолированные композиции. Сцена по-прежнему в памяти без нового формата проектов.

Проверка: сборка, 22 unit-теста и четыре реальных Electron UI-сценария. Добавлены проверки Shift/группового переноса, запрета закреплённых слоёв, разных меню, создания/группировки/переименования/удаления+Undo, вложенности/сворачивания/поиска, защиты от циклов, перетаскивания в папку, высоты окна и полностью пустой сцены. Снимок: `test-results/outliner-actions-final/outliner-context.png`.

### Удобное масштабирование · Electron

Общая математика в `src/interaction.mjs`, обработка ввода/отрисовка в `src/manipulator.jsx`. Применяется к изображениям, текстовым объектам и фигурам одной сцены, без отдельных систем трансформации. Изменение масштаба не перезаписывает исходную геометрию.

- Углы сохраняют пропорции, боковые ручки меняют одну ось. **Shift** переключает пропорциональность; **Alt** сохраняет центр. Клавиши можно менять во время жеста.
- Противоположный угол/середина ребра остаётся на месте, в том числе у повёрнутого и отражённого объекта. Сохраняется смещение точки захвата внутри зоны: нет начального скачка.
- Зона захвата зависит от скорости мыши и расстояния по тому же закону, что в Rust-версии: порог 260 px/s, коэффициент скорости, квадрат близости, предел расширения; сжимается с ограниченной скоростью. Радиус и прозрачность визуальной зоны сглаживаются отдельно, RAF прекращается после затухания.
- В настройках добавлены базовый радиус, расширение, коэффициент скорости, влияние расстояния и скорость сжатия. Зоны измеряются в экранных CSS px независимо от масштаба превью. Постоянные ручки не растут вместе с объектом; курсор учитывает поворот.
- Один жест — одна Undo-транзакция. Escape, потеря фокуса/захвата или pointer cancel возвращают исходное состояние. Заблокированные/скрытые объекты не имеют активных ручек. Ctrl/Cmd+Z во время жеста отменяет его.

Проверены 12 unit-тестов и два настоящих Electron UI-сценария: геометрия всех восьми ручек, отражение/поворот, инерция зон; corner/edge/Shift/Alt, no-jump, Undo/Redo/Escape/lock и UI 125% + preview 60%. По снимку при 125% исправлена лишняя пустота снизу (двойная компенсация CSS zoom); добавлена проверка высоты приложения. Снимок: `test-results/smart-resize/resize-zone.png`.

Ограничения масштабирования: при пересечении противоположной точки масштаб ограничен минимумом 0.02, переворот делается кнопками Flip. Максимальный модуль масштаба жеста — 100. Подключение растрового движка, сохранение настроек/проектов и редактирование пикселей — отдельные будущие этапы.

### Кольцо вращения

Общий манипулятор теперь содержит девятую адаптивную зону — вращение. Кольцо вокруг центра объекта с отступом 28 экранных CSS px от углов; у крошечных объектов радиус имеет нижний предел для доступности. Разрывы одинаковы для отрисовки и hit testing и рассчитаны по **максимальной** зоне ручки: base + expansion + 8 px, не по её текущему расширению. Масштабирование имеет приоритет; после захвата вращения оно не переключается на другую ручку.

Линия вдали от мыши полупрозрачна, ближайший участок белеет (distance fade 150 px). Подсветка — маленький круг на ближайшей точке кольца, движется вместе с курсором; радиус и прозрачность сглаживаются отдельно. Та же инерция расширения/сжатия, что у масштабирования. Вращение идёт вокруг неизменного центра, не затрагивает положение и масштаб. Shift: шаг 15°, Ctrl: точность ×0.1; Escape/потеря захвата отменяют, Undo/Redo — один жест. При переходе через ±180° угол накапливается без скачка, возможны полные обороты.

Проверены 16 unit-тестов и все три Electron UI-сценария (общий, resize, rotate). Дополнительно проверены центр локального круга возле курсора, gaps/fade, Shift/Ctrl, неизменность масштаба, Undo/Redo/Escape, приоритет угла, скрытие/блокировка. При просмотре снимка исправлено преобразование DOMPoint: его x/y нельзя получать object spread. Добавлен тест экранной позиции подсветки. Снимок: `test-results/rotation-final/rotation-ring-hover.png`.

### Компактная компоновка

`src/workspace.css` задаёт компактное оформление общих компонентов. Меню и инструменты находятся в одной строке 36 CSS px вместо трёх полос 35+32+46 px (выигрыш 77 px по высоте). Убраны отдельный заголовок Viewport, дублирующий caption холста, метка стека Electron/React и демонстрационные метаданные Details. Размер документа остаётся в status bar. Поиск и breadcrumb Content Browser совмещены с заголовком; стартовая высота браузера 180/160 px вместо 222/190. Никакие редакторные действия или панели не удалены. На малом экране Outliner прокручивается.

Проверка: сборка, 8 тестов и полный Electron UI-сценарий с новой геометрической проверкой общей верхней строки; просмотрены снимки большого/малого окна в `test-results/compact-workspace/`. Rust-редактор не менялся.

### Перемещение слоёв в Outliner

Перетащите подпись слоя в верхнюю или нижнюю половину другой строки: голубая линия показывает вставку до/после. Порядок сверху вниз соответствует стеку от переднего плана к заднему; меняется реальная последовательность SVG-отрисовки и карточек, не только сортировка списка. ID, выбранный объект и параметры сохраняются. Каждый завершённый перенос — одна Undo/Redo-транзакция; Escape и сброс вне строк отменяют перенос. Перенос на себя или в уже занимаемое место не создаёт Undo.

При поиске или алфавитной сортировке перенос выключен: кнопка `Layer order` очищает фильтр/сортировку и возвращает стек. Local/Global используют один компонент. Перенос строк отделён от перетаскивания панелей собственным MIME-типом; внешние данные не принимаются. Теперь поддержаны папки и наследование закрепления; у края списка есть автопрокрутка при drag-over.

Проверки этапа: 8 unit-тестов сборки/модели и полный Electron UI-сценарий, включая настоящий drag вверх/вниз, SVG stack, Undo/Redo, ограничения при поиске/сортировке, маркер вставки и Escape. Снимки этого этапа: `test-results/layer-reorder/`.

- Общие React-компоненты Button, Icon, Panel, NumberField и Outliner; тема/размеры задаются в `src/style.css`.
- Выбор синхронизирован между Outliner, Details, SVG-холстом и карточками Content Browser.
- Поиск/сортировка Outliner, Local/Global, видимость; поиск/категории Content Browser.
- Позиция, масштаб, связь осей, поворот, прозрачность, Flip, блокировка, имя и текст. Изменения сразу отражаются на холсте.
- Перемещение объектов мышью с одной Undo-транзакцией; Escape отменяет ввод/перемещение, Enter подтверждает число. Undo/Redo кнопками и Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z.
- Изменение ширины sidebar и высоты Content Browser разделителями. Перетаскивание вкладки Outliner на Details и обратно меняет их местами (не универсальный docking).
- Масштаб всего UI, сетка и отключение анимаций в настройках. Состояние только в памяти.

### Жесты имени и вложенное Edit

Быстрый нативный двойной клик по имени папки сворачивает/разворачивает её. Повторный одиночный клик по уже выбранному имени с паузой 500–1800 мс и перемещением не более 5 CSS px запускает inline Rename. После второго клика есть защитная задержка 500 мс: следующая попытка быстрого двойного клика отменяет переименование. Один клик сам по себе редактор не открывает. Shift/Ctrl/Cmd сохраняют выбор нескольких объектов; заблокированное имя не редактируется. Начало drag, другой pointer down, Escape, потеря фокуса и изменение данных/представления отменяют ожидающее переименование.

Контекстное меню: `Object → Edit → Edit properties / Rename (F2)`. Подменю открывается наведением, кликом или ArrowRight, закрывается ArrowLeft/Escape; Up/Down/Home/End перемещают фокус. У края окна оно открывается влево. F2 остаётся доступен непосредственно в дереве. Enter/Escape/blur, Undo/Redo и переименование в строке сохранены. Команды, которые ещё не реализованы (Cut/Copy/Paste и т. п.), не имитируются.

Проверка этого этапа: 32 unit-теста проходят. Новые жесты, клавиатурное/мышиное подменю, inline Rename и иерархия проходят в настоящем Electron. Запущены все 6 UI-сценариев: общий сценарий и проверки Outliner проходят; тест масштабирования нестабилен при проверке Undo (отдельный повтор успешен), у проверки fade вращения также был один сбой до успешных повторов. Код манипулятора на этом этапе не менялся; причина нестабильности этих двух проверок ещё не установлена. Снимки жестов и Edit: `test-results/gestures-verified/`.

### Создание папок в строке и универсальная вложенность

`Create folder` и `Move to new folder` сразу создают настоящую папку, выбирают её и открывают общее поле InlineRename с выделенным именем `New folder`. Модального диалога больше нет. Enter подтверждает имя, Escape оставляет папку с исходным именем, уход фокуса применяет непустое имя. Создание/группировка и последующее переименование — отдельные Undo-транзакции. Поиск/сортировка сбрасываются, раскрываются только необходимые предки, новая строка прокручивается в видимую область.

Любой объект может быть родителем: перенос в центральные 50% строки устанавливает `parentId`, верхняя/нижняя четверти вставляют рядом. Тип и иконка родителя остаются прежними; при появлении детей добавляется стрелка раскрытия и поддерживается быстрый двойной клик. Перенос не меняет координаты/масштаб/поворот; это пока организационная иерархия, не наследование Transform. Видимость и блокировки наследуются; цикл, перенос в себя и перенос в заблокированный объект запрещены. Папки по-прежнему не рисуют пиксели. Проверки: 34 unit-теста, сценарий `tests/parenting-ui.mjs`, обновлённые проверки Outliner и жестов. Снимки: `test-results/parenting-verified/`.

### Наследование свойств родителей

Иерархия теперь влияет на изображение: позиция, поворот, масштаб и Flip родителя применяются ко всем потомкам, прозрачности перемножаются по всей цепочке. Папки получили Transform и Opacity в Details, но не рисуют собственных пикселей. Видимость и блокировка по-прежнему наследуются. Данные детей не переписываются при изменении родителя: общий affine-расчёт в `src/scene-transform.mjs` используется моделью переподчинения, SVG и манипулятором.

При смене родителя сохраняется мировая геометрия через `parentOffset` (parent-inverse binding), включая отражения, неравномерный масштаб и возникающий shear. Это постоянная матрица привязки; последующие изменения родителя уже действуют на ребёнка. Прозрачность при переподчинении сразу получает множитель нового родителя. Детские числовые параметры сохраняются в рабочем пространстве этой привязки. У родителя с нулевым масштабом нельзя вычислить обратную матрицу: перенос внутрь отвергается, манипуляторы потомков недоступны до восстановления масштаба. Pivot пока прежний — центр геометрии; у папки это центр области композиции 960×600. Нет группового offscreen-compositing: Opacity умножается для каждого drawable, а не применяется к предварительно сведённой группе. Будущие эффекты не объявляются автоматически наследуемыми.

Добавлены 5 unit-тестов матриц/рекурсивного наследования и `tests/inheritance-ui.mjs`: вложенные перемещение/поворот/неравномерный масштаб, Opacity, keep-world, совпадение ручек с экранной геометрией, перемещение/anchored resize дочернего объекта и параметры папки. Всего проходят 39 unit-тестов; новый UI-сценарий повторно прошёл, также успешно выполнены все 7 прежних сценариев Electron. Для нового DnD-сценария используется реальное перемещение мыши с ожиданием маркера drop-inside перед отпусканием. Снимок: `test-results/inheritance-final3/inherited-transforms.png`. Это заменяет ограничение «организационная иерархия» предыдущего этапа; формат файлов основного редактора не менялся.

### Инструменты рисования, текста, изображений и навигации

Общий класс `Tool` и реестр в `src/tools.mjs` содержат ID, имя, иконку, горячую клавишу, курсор, подсказку, описания параметров/диапазоны/defaults/валидацию, привязку параметров к выбранному объекту (`edits`, `valueFor`, `patchFor`) и обработчики `begin/move/end`. `src/tool-ui.jsx` строит вертикальную панель и строку параметров из этих данных. `src/tool-canvas.jsx` предоставляет контекст жеста: создание/изменение/выбор объектов, текущие параметры и состояние жеста. Для нового инструмента добавляется экземпляр `Tool` с поведением; для существующих типов параметров отдельная форма React не нужна. Инструменты не зависят от React; рендеринг содержимого и растровых модификаторов отделён от панели.

Рабочие инструменты:

- V: Selection — существующие перемещение, умный масштаб и кольцо вращения.
- B: Brush — круглая кисть, размер/цвет/прозрачность, видимый контур курсора. Каждый штрих — самостоятельный слой Drawing и одна Undo-транзакция; параметры выбранного штриха можно менять.
- E: Eraser — неразрушающая маска выбранного незаблокированного drawable, с преобразованием в его локальное пространство. Подходит также для импортированного изображения. Undo возвращает стёртое. При анизотропной трансформации ширина маски оценивается по одной оси обратной матрицы.
- T: Text — клик создаёт текст; клик по тексту или двойной клик в Selection открывает textarea непосредственно на холсте. Есть нативное выделение/замена букв, многострочность, шрифт/размер/цвет. Ctrl/Cmd+Enter завершает, Escape отменяет текущую правку, blur применяет. При изменении содержимого/шрифта растут intrinsic bounds, буквы не ограничиваются старым прямоугольником. Создание и последующая правка текста — разные Undo-транзакции.
- R/O: Rectangle/Ellipse — создание перетаскиванием, Shift ограничивает квадратом/кругом; заливка, обводка и её ширина привязаны также к выбранной фигуре.
- I: Image adjustments — импорт выбранного пользователем PNG/JPEG/WebP до 25 MB и 40 MP; исходный data URL остаётся в памяти, отображаемый размер вписывается в 800×500. Яркость, контраст и насыщенность реализованы SVG-фильтром, оригинал не переписывается.
- H: Hand — перемещение вида. Дополнительно Space+drag и средняя кнопка работают без переключения инструмента.
- Z: Zoom — клик приближает, Alt+клик отдаляет. Колёсико масштабирует вокруг курсора, меню Preview предлагает 10–800%, Fit canvas вписывает холст с учётом ширины и высоты окна. Проценты Preview по-прежнему заданы относительно ширины viewport, не масштаба исходного растра 1:1. Навигация не меняет документ и Undo.

Escape/pointer cancel/потеря захвата или фокуса отменяют незавершённый рисующий жест; Ctrl/Cmd+Z во время него также отменяет только текущий жест. При смене инструмента начатый штрих завершается. Горячие клавиши не перехватываются в полях ввода. Новая строка параметров компактна и горизонтально прокручивается на узком окне; стили и SVG-иконки общие. Нативные системные color/file pickers пока сохранены.

Это первый рабочий набор поверх SVG-прототипа, а не полноценный растровый движок: пока нет пиксельного painting backend, ретуши/клонирования/заливки, crop, экспорта, записи проекта или персистентности настроек. Штрихи являются векторными путями, ластик — SVG-маской, цветокоррекция — SVG-фильтром. Основной Rust-редактор и его формат проектов не менялись.

Проверки этапа: сборка, 46 unit-тестов; `tests/tools-ui.mjs` проверяет реальные рисование/стирание, Undo/Redo, фигуры/Escape, текст/авторазмер/отмену правки, pan, Space, zoom-under-cursor/Fit, импорт локального PNG и коррекцию. Повторно выполнены восемь прежних UI-сценариев. В тесте наследования добавлена прокрутка строки в видимую область до drag: новая строка параметров уменьшила доступную высоту Outliner. Снимок общего интерфейса: `test-results/tools-finish/tools-editor.png`.

### Общие числовые поля и рамки по содержимому

`ScrubNumber` в `src/scrub-number.jsx` используется и в Details, и для всех параметров инструмента типа number. Вместо нативных стрелок: нажать на число и тянуть горизонтально (порог 3 px), Shift ×10, Ctrl/Cmd ×0.1, ограничения/step берутся из описания параметра. Клик/двойной клик позволяют вводить число вручную, Enter завершает, Escape отменяет. Сохраняется клавиатурная доступность spinbutton без визуальных стрелок. Завершённый drag — одна Undo-транзакция; pointer cancel, потеря фокуса окна и Ctrl/Cmd+Z во время drag отменяют его.

У Rectangle/Ellipse появились Width/Height в автоматически созданной панели инструмента и Size в Details. Они меняют intrinsic-геометрию уже созданной фигуры, не создавая новый объект. V возвращает режим умной трансформации. В Details текста добавлена явная кнопка `Edit text on canvas`, которая переключает инструмент и фокусирует редактор непосредственно на холсте; остаются T и двойной клик в Selection.

`src/content-bounds.mjs` отделяет аналитическую рамку содержимого от intrinsic-размера и системы координат трансформации. Drawing учитывает точки и радиус кисти; новые штрихи создаются с компактными локальными координатами вместо размера 960×600. Для Layer/Folder рамка объединяет видимых потомков с учётом вложенных affine-трансформаций; пустой контейнер не получает фиктивную рамку. У обычного drawable учитывается также дочернее содержимое. Рамка обновляется при перемещении/изменении/скрытии детей, не переписывая их данные и не сдвигая геометрию. Старые широкие Drawing также выделяются по точкам, а не по сохранённому width/height.

Общий манипулятор поддерживает рамку с ненулевым локальным origin: resize сохраняет противоположный anchor, кольцо вращается вокруг центра содержимого. Числовой поворот также компенсирует положение, чтобы центр содержимого не уезжал. У маленькой точки центральная часть остаётся зоной перемещения вместо перекрывающихся зон resize. Контейнеры теперь имеют восемь ручек и могут перемещаться за собственную рамку. Расчёт геометрический, а не пиксельный: обрезки прозрачностью/ластиком не сужают рамку, границы текста основаны на его текстовом блоке, stroke фигур не включён в их intrinsic-прямоугольник. Это не новый формат проектов и не новый растровый backend.

Добавлены unit-тесты компактных штрихов, аналитических рамок, скрытия детей, offset-anchor и коэффициентов scrub; UI-сценарий `tests/scrub-bounds-ui.mjs` проверяет drag чисел в двух панелях, Undo/Escape, размеры готового прямоугольника, перемещение/resize точки, рамку/resize папки и явное редактирование текста на холсте. `tests/tools-ui.mjs` теперь явно выбирает восстановленный после Redo штрих перед проверкой ластика. Итог: сборка, все 52 unit-теста и все 10 UI-сценариев прошли последовательным прогоном без повторных запусков. Снимок: `test-results/scrub-final-check/scrub-and-content-bounds.png`.

### Выбор по иерархии, рисование в слое и мультиинструмент фигур

`CanvasPick` в `src/canvas-pick.mjs` выбирает сначала верхнего родителя попавшего под курсор объекта. Повторные клики в том же месте (допуск 4 px) углубляют выбор до самого объекта. Drag/другое место/другое попадание сбрасывают последовательность; Outliner остаётся прямым выбором. Граница выбранного контейнера отдельно доступна для перемещения; прозрачный внутренний прямоугольник больше не перекрывает дочерние объекты.

Кисть пишет штрихи в массив `paint` выбранного незаблокированного видимого объекта, в его локальных координатах. Это касается в том числе Layer, изображения, фигуры и папки: выбор сохраняется, каждый штрих не создаёт новый слой. При пустом выборе остаётся создание нового Drawing. Ластик маскирует также новые штрихи. Существующая маска применяется ко всему содержимому слоя, включая дальнейшие штрихи; индивидуальный порядок paint/erase пока не является независимым стеком операций. Одна линия — одна Undo-транзакция. В рисующих режимах нет рамки/ручек/кольца; они показываются только в Selection и Shapes/Edit. При рисовании рамки содержимого не пересчитываются без необходимости.

Shapes — единый экземпляр `Tool` с вариантами Rectangle/Ellipse и режимами Create/Edit в описании параметров. После рисования автоматически включается Edit: доступны существующие умный resize, перемещение, вращение и параметры фигуры, повторный drag не создаёт случайную копию. Create возвращает создание следующей фигуры. Варианты доступны и через select Shape, и через ПКМ по кнопке Shapes (клавиатура меню: Up/Down, Enter, Escape). U выбирает общий инструмент, R/O — создание Rectangle/Ellipse. Признак режима хранится в настройках инструмента, не в объекте документа.

В строке параметров вместо названия — иконка инструмента; цветовой образец занимает почти всё поле, рамка и внутренний отступ уменьшены. Числа с шагом >=1 при drag округляются к удобным величинам: <10 к 0.5, <100 к 1, далее к десяткам/сотням и т. д. с усечением к нулю. Примеры: 1.645→1.5, 25.123→25, 125→120, 1579→1500. Ctrl/Cmd сохраняет точную подстройку; дробные transform-параметры с шагом .01 не получают грубого округления. При создании фигуры её размеры округляются тем же правилом. Ручной ввод остаётся точным в пределах ограничений модели, без прежнего принудительного отображения трёх знаков; координаты событий курсора очищены от погрешности матрицы до 4 знаков.

Добавлены `tests/workflow.test.mjs` и `tests/workflow-ui.mjs`: parent-first/child picking, округление, paint bounds, create/edit metadata, несколько штрихов в одном слое, отсутствие рамки при рисовании, lock guard, точный ввод, меню фигур и автоматический переход в Edit. Старые UI-тесты адаптированы к одному инструменту и отсутствию рамки в Text/Brush. Тест наследования явно выбирает дочерний объект после Undo перед проверкой его ручек — сцена теперь сначала выбирает родителя. В тесте Rename добавлено ожидание кадрового восстановления фокуса перед следующим F2. Итог: сборка и 56 unit-тестов прошли; успешно выполнены все 11 UI-сценариев, включая повтор оставшихся проверок после исправления ожидания фокуса в тесте. Снимки: `test-results/workflow-complete/`.

### Обводка и общие команды редактора

Обводка Rectangle/Ellipse использует `vector-effect="non-scaling-stroke"`: изменение размеров/масштаба/отражения фигуры, в том числе через родителя, не утолщает линию. Значение Outline width меняется только самим параметром. Сейчас это экранная толщина SVG: она не увеличивается и при зуме холста.

`src/editor-commands.mjs` содержит описания, горячие клавиши, проверки доступности и чистые операции копирования/вставки. Общий dispatcher приложения обслуживает клавиатуру, Edit и контекстный Edit Outliner:

- Delete/Backspace — удалить; Ctrl/Cmd+C/X/V — копировать/вырезать/вставить объекты.
- Ctrl/Cmd+D — дублировать; Ctrl/Cmd+A — выделить все объекты.
- Ctrl/Cmd+Z — Undo; Ctrl/Cmd+Shift+Z или Ctrl/Cmd+Y — Redo.

Copy захватывает выбранные поддеревья один раз (без повторного копирования ребёнка вместе с выбранным родителем). Paste/Duplicate создают новые ID, сохраняют внутренние parentId, paint/маски/текст/изображения и мировую геометрию с наследованной прозрачностью; корни вставляются в корень сцены со сдвигом 20 px, последующие Paste — 40, 60 и т. д. Копирование не меняет сцену; Cut/Delete/Paste/Duplicate — одна Undo-транзакция. После изменений синхронизируются выделение, Outliner, Details и холст.

Удаление/вырезание защищены от изменения закреплённого объекта/предка/потомка. Если в выбранном наборе есть закреплённые объекты, удаление всего набора недоступно; Select all включает и закреплённые. Copy/Duplicate закреплённого объекта допустимы, закрепление копии сохраняется. Доступность команд в меню вычисляется теми же проверками, что клавиатура. В полях ввода/contenteditable работают штатные текстовые Delete/Copy/Paste/Select all, а не команды объектов; модальные настройки также не пропускают команды изменения документа.

Буфер объектов внутренний, только в текущем окне/сеансе: он не читает и не перезаписывает системный буфер и не поддерживает вставку объектов из другого экземпляра/приложения. Текстовый системный буфер продолжает работать нативно. Для внешних изображений остаётся Import image. Новые проверки — `tests/editor-commands.test.mjs` и `tests/commands-ui.mjs` (включая настоящий текстовый Ctrl+C/V в textarea). Сборка и все 60 unit-тестов прошли. Выполнены все 12 UI-сценариев; старые pointer-сценарии потребовали повторов и уточнений ожиданий/видимости цели (ожидание смены инструмента, прокрутка числового поля, уменьшение зума перед жестом над перемещённым потомком). Тесты меню учитывают доступность Copy при множественном выборе и новые подписи shortcuts. Новая проверка команд прошла повторно. Снимок: `test-results/commands-last/fixed-outline-and-commands.png`.

## Фоторедактор: инструменты, ресурсы и первый Effects Graph

### Продолжение: свободный граф и файлы проектов

Effects Graph теперь использует сохраняемую модель DAG, а не только сводную линейную
цепочку. Перемещайте ноды за названия; соединяйте выход справа со входом слева
перетаскиванием или двумя кликами. У Add/Subtract два входа: `base` и `mask`.
Один выход может использоваться несколькими операциями. Соединение занятого входа
заменяет прежний провод; цикл/несовместимое соединение отвергаются без Undo-записи.
Новые связи реально вычисляются SVG-рендерером: в отключённом Output нет результата.
Input — исходное содержимое, Paint_Mask — редактируемая маска, NodeInput — сигнал
дочернего объекта. Add накладывает сигнал, Subtract вычитает его альфа-покрытие.

Двойной клик по проводу разрывает его (также Enter/Delete при фокусе на проводе).
Delete на выбранной ноде удаляет её и провода, но не исходные мазки; Input/Output
защищены. Reset graph восстанавливает автоматические связи и исходные ноды, Undo
возвращает ручную схему. Движение нод — одна транзакция; Escape/потеря фокуса отменяют.
Создание нод — ПКМ по пустому месту графа: поиск и категории Operations / Object sources.
Fit graph / Reset graph также перенесены в это меню. Верхние панели и нижняя памятка
удалены, названия нод и портов увеличены. ЛКМ по пустоте снимает выделение ноды.
Протягивание ЛКМ по пустоте выделяет ноды прямоугольником; Shift добавляет к выделению,
Ctrl/Shift+клик переключает отдельную ноду, Ctrl+A выделяет все. Выделенные ноды
перемещаются вместе за любой заголовок; Delete удаляет группу одной Undo-транзакцией.
Input/Output защищены от удаления. Escape отменяет рамку/перемещение.
После добавления нод выполняется детерминированная расстановка по зависимостям,
без пересечений карточек, и граф вписывается в окно. Простое редактирование существующих
масок и изменение проводов не сбрасывают ручное расположение нод.
Владелец открытого графа зафиксирован: выбор/перенос объекта в Outliner и выбор NodeInput
не заменяют граф. Для смены владельца нажмите Effects Graph в Details нужного объекта.
Дочерний объект можно перетащить из Outliner или с холста в граф. Перенос с холста
на любую панель возвращает исходную позицию и временно показывает объект полупрозрачным;
в графе дополнительно создаётся NodeInput. Ссылки пока ограничены потомками владельца.
Колёсико масштабирует граф относительно курсора; ПКМ, средняя кнопка или Space+ЛКМ
перемещают поле. Отдельного поля процентов нет; Fit graph вписывает и центрирует ноды.
Окно графа по умолчанию шире обычных настроек. Выбранная Paint_Mask показывается
диагональной штриховкой по её альфа-покрытию, включая мягкие края и вырезанные участки.
Редактирование кистью/ластиком пересчитывает результат во время движения, до отпускания мыши.
Рамки трансформации не включают отключённые положительные ветви. После Subtract
границы остаются консервативными: точное вычисление оставшихся пикселей не реализовано.

File → Save project / Ctrl+S сохраняет `.mycutproject`; первый раз открывается системный
диалог, затем используется выбранный файл. Save project as… / Ctrl+Shift+S позволяет
выбрать другой файл. Open project… / Ctrl+O проверяет файл перед заменой сцены,
при изменённом документе просит подтверждение. Отмена/ошибка оставляют текущую сцену.
Сохраняются слои, встроенные изображения, ресурсы Content Browser, маски/сегменты,
NodeInput, координаты нод и соединения, zoom/pan холста и параметры инструментов.
История Undo, положение dock-окон и автосохранение в этот формат пока не входят.
При открытии история начинается заново. Звёздочка в заголовке означает изменения;
закрытие приложения пока не показывает диалог сохранения — сохраняйте перед выходом.

Формат — JSON `mycut-project`, версия 1, максимум 128 MB. Валидируются иерархия,
идентификаторы, числовые значения, стили, мазки, ссылки и граф; удалённые/file URL
в изображениях запрещены, принимаются встроенные PNG/JPEG/WebP. Для ручного графа
лимит 64 ноды / 128 связей и сложность вычисления 2048. При достижении лимита новая
маска не добавляется: можно продолжать существующую Paint_Mask. Multiply/Intersect,
произвольные GPU-шейдеры и несколько независимых композиций ещё не реализованы.

Renderer остаётся sandboxed и без Node. Узкий preload-мост предоставляет только
Save/Open project; renderer не передаёт произвольных путей. Main принимает вызовы
только из локального главного frame, не открывает параллельные project-диалоги,
проверяет JSON и пишет через уникальный временный файл с sync перед rename.
Если запись не удалась, временный файл убирается, прежний проект не заменяется.

Проверки: `npm run test:projects` — pure tests графа/формата и настоящий Electron.
Диалоги в UI-тесте подменены внутри тестового процесса; проверяется реальная запись
и чтение `test-results/free-graph/roundtrip.mycutproject`, включая встроенное изображение,
связи и координаты, отказ на повреждённом файле и отмена Save As. Скриншот —
`test-results/free-graph/free-graph.png`.

Фигуры: в верхней строке Mode / Shape / Color / Outline / Outline width. Размеры
вторичны (Details → Size или расширенные настройки). Добавлены Corner radius и
Solid / Dashed / Dotted. В режиме Edit круглая ручка внутри прямоугольника меняет
общий радиус углов; один drag — одна Undo-транзакция, Escape отменяет. Двойной клик
Selection по фигуре включает Shapes / Edit, по тексту — Text / Edit и inline editor.
Hit-test использует фактический объект под курсором, а не retarget захвата pointer.

Текст: общий Tool описывает Mode Create/Edit, Type Point/Paragraph, шрифт, размер,
цвет, насыщенность, курсив, выравнивание, межстрочный и межбуквенный интервалы.
Paragraph переносится по заданной ширине; это простой браузерный перенос по символам,
не полный движок типографики/текста по кривой. Корректная сложная типографика,
индивидуальные стили диапазонов и вертикальный текст пока не реализованы.

Общие обработчики импорта принимают PNG/JPEG/WebP до 25 MB и 40 MP: выбор файла,
Ctrl/Cmd+V из системного буфера вне текстовых полей, drop файлов Проводника на холст.
Drop использует координаты холста с учётом pan/zoom. Несколько изображений импортируются
одной Undo-транзакцией. Свежий внутренний Copy/Cut имеет приоритет над старой картинкой
в системном буфере; после ухода фокуса в другую программу предпочтение получает внешний
буфер. Этот эвристический выбор не следит за системным буфером в фоне.

Content Browser больше не отражает scene items. В нём одна текущая композиция,
импортированные изображения и отдельные PNG-ресурсы, созданные Export layer to assets.
PNG слоя включает его дочерние объекты, но не остальную композицию, на прозрачной
рамке 960×600. Текст перед экспортом растеризуется загруженным браузерным шрифтом,
чтобы отдельное SVG-изображение не теряло Roboto. Двойной клик/drag ресурса создаёт
новый независимый слой. Content Browser использует DockPanel: можно оторвать,
объединить с другими вкладками и вернуть крестиком; пустая нижняя область схлопывается.
Ресурсы и композицию теперь можно сохранить в `.mycutproject` (см. продолжение выше).

Move to new layer группирует выделение в Layer с сохранением мировой геометрии,
так же, как Move to new folder. Details ограничивает ширину контролов и оставляет
свободный spacer справа; кнопки вертикального toolbar меняют высоту при наведении.
Цель нового docking появляется только возле соответствующего края, не все четыре сразу.
В жестовом заголовке добавлено perspective-превью двух карточек с влиянием позиции мыши
снаружи: вход снизу активирует анимацию на 0.5 s. Это окно визуального feedback;
распознавание полукруга по-прежнему геометрическое, без ограничения скорости.

Effects Graph открывается кнопкой внизу Details и использует общий DockPanel.
Для каждого объекта строится цепочка Input → Add/Subtract → Paint_Mask → Output
из его paint/erasures. Выбор Paint_Mask открывает Enabled/Opacity и команды редактирования
в Details; на холсте виден полупрозрачный preview. Brush/Eraser редактируют выбранную
маску сегментами, не создавая новую ноду; Undo и Escape используют общий history.
Дочерний объект можно перетащить из Outliner в граф или выбрать в Add child as NodeInput.
Поддержаны Add/Subtract и opacity сигнала; сам источник и его поддерево не рисуются
самостоятельно, пока источник не выбран напрямую или через NodeInput. Выбор NodeInput
выделяет сам объект для трансформаций, при этом сохраняет контекст родительского графа.
Выбор другого объекта меняет граф. Циклические/посторонние/повторные сигналы отвергаются.

Этот первый линейный вариант расширен свободными соединениями портов и сохранением
графа на диск; текущие возможности и ограничения описаны в продолжении выше.

## Предыдущие изменения жестового заголовка

Обновление заголовков и пустых зон:

- В объединённых вкладках убраны повторяющиеся иконки. В жестовом режиме видны
  только название активной панели и кнопки управления (шестерёнка / pin / close).
  Высота зоны жеста — 78 px; курсор оставляет голубой след, затухающий за 420 ms.
  При отключённой анимации / prefers-reduced-motion след не рисуется.
- Вся свободная поверхность жестового заголовка переносит группу целиком с ЛКМ.
  Отдельной ручки нет. Без жестового режима вкладки можно отрывать по одной.
- Пустая область и её разделитель полностью скрываются, холст получает её ширину.
  Во время переноса окна появляются четыре цели у краёв рабочей области: слева,
  справа (вертикальная область), сверху, снизу (горизонтальная). Подсветка показывает
  будущий размер; Escape отменяет перенос без создания пустой области.
- Для разделения существующей группы есть Split horizontally / Split vertically
  в шестерёнке, а также перенос к границам панели. Постоянной кнопки-сетки в
  объединённом заголовке нет.

UI-проверка этого обновления: `tests/gesture-chrome-ui.mjs`; снимки —
`test-results/gesture-chrome/`. Старое описание боковых иконок ниже заменено этим
поведением; порядок панелей gestureOrder остаётся тем же.

Advanced перенесён в нижний футер окна настроек: в базовом виде находится у нижней границы,
при прокрутке расширенных настроек остаётся доступным. Основные группы остаются видимыми;
внутренних вкладок Basic / Advanced нет.

У группы с двумя и более вкладками появляется настоящая кнопка-шестерёнка Panel group
settings. В её меню Gesture switching включает/выключает жестовый режим только этой группы.
Заголовок становится выше, названия вкладок заменяются иконками по краям, в центре показана
активная панель. Для Outliner / Details: Outliner слева, Details справа (порядок задаётся
метаданными gestureOrder). Иконками также можно переключать обычным кликом.

Переключение теперь основано на позиции мыши, без нажатия: левая зона заголовка (28 %)
выбирает предыдущую панель, правая — следующую. Небольшая выдержка 110 ms отсеивает случайный
проход курсора. Центральная зона нейтральна и повторно разрешает жест. После переключения
удержание курсора у края не циклически перебирает панели; выход из заголовка также сбрасывает
анализ. Escape, pointercancel, потеря фокуса и нажатая кнопка мыши сбрасывают распознавание.
Область содержимого панели не перехватывается, документ и Undo не меняются.

Переключение сопровождается slide/fade содержимого за 220 ms и названия за 180 ms.
Используются настоящие browser animations без пересоздания содержимого. Быстрый следующий
переход отменяет предыдущую анимацию. Учитываются prefers-reduced-motion и выключенная
анимация интерфейса; иконки плавно меняют активное состояние.

Отдельный значок четырёх стрелок удалён. Docking остаётся обычным перетаскиванием вкладки
или центрального заголовка с нажатой ЛКМ; этот жест не запускает hover-переключение.
Шестерёнка есть у каждого окна. При одной вкладке скрыты только жестовые настройки.
Auto-hide window сворачивает окно после ухода курсора в полоску; наведение раскрывает его.
В split-разметке направление полоски определяется ближайшим разделением: горизонтальная
полоска при расположении панелей сверху/снизу, вертикальная — слева/справа. Соседняя
панель получает свободное место при включении Auto-hide. После этого слот полоски
имеет постоянный размер: раскрытие идёт поверх рабочей области, не сдвигая, не
растягивая и не перерисовывая соседнюю панель. Окна не меняются местами: каждое
раскрывается к собственной правой границе (крайнее правое — к стене), горизонтальная
полоска раскрывается вверх. Переход за 280 ms использует обрезку без масштабирования
текста. Открытие и закрытие начинаются через 100 ms наведения/ухода курсора; при наведении полоска плавно светлеет. Замочек возле шестерёнки удерживает окно открытым.
Ручка изменения размера раскрытого окна меняет только его сохранённую ширину/высоту;
во время изменения размера таймер выключен и запускается заново после отпускания.
При выключенной анимации интерфейса / prefers-reduced-motion переход мгновенный.
Состояние полей и содержимое сохраняются. Content Browser при сворачивании освобождает
место холсту. Настройка автоскрытия, как и layout, действует в текущем сеансе.
Перенос за свободное место в заголовке не выполняет docking; вкладка сохраняет docking.
Настройка хранится в layout группы в текущем сеансе, не на диске.

В шестерёнке доступны два режима: Position (описан выше) и Semicircle. Второй
распознаёт траекторию вверх → вправо → вниз для правой вкладки и зеркальную для
левой. Начало — внутри динамического заголовка или вход в него снизу; выход за его
границы допустим в пределах 24–48 px без ограничения времени. Если начатый жест ушёл
далеко вверх, он сохраняется ещё 1500 ms: возврат и завершение вниз засчитываются.
Внутри зоны ограничения скорости нет. Прямой проход и мелкое дрожание не переключают.
Для следующего полукруга войдите в заголовок заново снизу. Нажатие кнопки, Escape,
потеря фокуса и истечение времени возврата отменяют незавершённую траекторию.
Объёмный индикатор — две страницы с общим корешком и иконками панелей под 90°, вращающиеся вместе
от позиции мыши; перетаскивание с ЛКМ остаётся docking.

Каждый расширенный параметр кисти дополнительно помечен маленьким значком настроек
с подсказкой Advanced parameter. Основная иконка типа параметра сохранена.
Проверки второго режима: `tests/tab-gesture.test.mjs`, `tests/arc-tabs-ui.mjs`.
Запуск обоих UI-сценариев жестов: `npm run test:gestures`.

## Настройки: базовый вид и расширение без внутренних вкладок

Внутренние Basic / Advanced больше не вкладки. При открытии всегда показаны основные
параметры. Кнопка Advanced settings раскрывает дополнительные поля, не убирая основные.
Группы и иконки берутся из метаданных Tool; для кисти: Tip shape, Paint, Smoothing,
Pen dynamics. Другие инструменты используют Geometry, Outline, Typography, Image adjustments.
Вкладки самих окон (Details / Brush settings) и docking сохранены.

Каждый ползунок инструмента теперь имеет общее поле ScrubNumber для точного ввода и
перетаскивания числа. Smoothing принимает любое конечное неотрицательное значение, включая
3.751234: предел 1 снят и в UI/валидации, и в brush-engine. Значение выше 1 усиливает
стабилизацию, не обрезаясь при записи в штрих. Сам ползунок оставлен в удобном диапазоне
0–1; большие значения вводятся в соседнее поле. Для Opacity / Hardness / Flow / Roundness
физические границы долей сохранены, а не бессмысленно расширены за 100 %.

Группировка и список basic-полей заданы централизованно в Tool. Числа вводятся без
автоокругления; NaN/Infinity отклоняются. При скрытии расширенных параметров их значения
сохраняются, а следующее открытие окна снова начинается с базового вида.

Проверено: сборка, 77 unit-тестов; tool-settings-ui, brush-ui, layout-ui, panels-ui,
docking-ui, scrub-bounds-ui и tools-ui прошли. Новый тест проверяет отсутствие внутренних
вкладок, постоянную видимость basic, группы, ручной ввод 3.751234, сохранение значения и
его попадание в реальный нарисованный штрих. Снимки: test-results/tool-settings/.

## Разделение областей по горизонтали и вертикали

Перетаскивание вкладки теперь поддерживает возврат окна не только в строку вкладок:
у края тела dock-панели появляется подсветка половины области. Отпускание снизу/сверху
создаёт вертикальное разделение, слева/справа — горизонтальное. В центре или на заголовке
остаётся объединение вкладок. Плавающее окно можно так вернуть под Outliner, как на эскизе.
Подсветка и drop используют один hit-test; обе текстовые подписи предпросмотра удалены.

Sidebar хранит дерево вложенных split-областей через маршруты групп. Каждый разделитель
перетаскивается мышью или изменяется стрелками; удаление/отрыв последней вкладки сворачивает
пустую ветвь и отдаёт площадь оставшейся панели. Содержимое и поиск сохраняются. Крестик
обычного floating-окна теперь возвращает отдельную область, а не теряет её среди вкладок.
Общую ширину sidebar можно увеличить сверх прежних 520 px (оставляя холсту 360 px), чтобы
горизонтальные колонки были удобны. Автоматического расширения при drop нет — подсветка
точно соответствует выбранной области.

Это split-docking панелей sidebar. Сам viewport и Content Browser пока остаются в основном
layout; тело другой floating-группы объединяет вкладки, а не создаёт вложенные splits.
Сохранения layout между запусками и отдельных native OS-окон пока нет.

Проверено: сборка, 75 unit-тестов; docking-ui, split-docking-ui, ui, outliner-ui, panels-ui.
Новый UI-тест возвращает Details всеми четырьмя способами, проверяет отсутствие надписей,
вложенный split с настройками кисти, сохранение поиска и перетаскивание границы.
Снимок: test-results/split-docking/nested-horizontal-vertical.png.

## Перетаскивание и объединение плавающих вкладок

Outliner, Details и все плавающие настройки инструментов используют общий DockProvider /
DockPanel / DockGroup. И закреплённое, и незакреплённое окно всегда имеют одинаковый
заголовок-вкладку, как у Details. Закрепление меняет автозакрытие, а не оформление,
размер или положение окна; оно остаётся плавающим. Basic / Advanced — это
внутренние вкладки настроек, а Brush settings — переносимая вкладка самого окна.

- Потянуть вкладку за название и отпустить на строке вкладок другой группы: объединить.
- Отпустить вне строки вкладок: отделить в плавающее окно (или передвинуть одиночное).
- Плавающие группы объединяются между собой и с группами боковой панели.
- Перенос на другую вкладку также меняет порядок. Escape отменяет начатый перенос.
- Крестик у обычной плавающей панели возвращает её в sidebar; у настроек закрывает их.
- Если sidebar пуст, панель можно вернуть, отпустив вкладку на область с подсказкой.
- Кнопка-сетка остаётся быстрым способом объединения/разделения sidebar.

При переносе подсвечивается вся принимающая группа и показывается вертикальный маркер
позиции вставки вкладки. Над свободной областью вместо этого виден пунктирный контур
будущего floating-окна. Подсказки не перехватывают указатель; тот же hit-test используется
для предпросмотра и фактической вставки. Подсветка исчезает после отпускания или отмены.
Незакреплённые настройки всё ещё закрываются первым внешним жестом, не пропуская его
на холст. Их тоже можно переносить за вкладку; при объединении с другой группой они
автоматически закрепляются. Старый отдельный компонент FloatingPanel удалён: состояния
pin/unpin больше не переключают реализацию окна.

Содержимое рендерится в постоянный DOM-host (React portal); переносится host, а не
заново создаётся Outliner/редактор. Поиск, настройки и локальное состояние не сбрасываются;
там, где поддерживается DOM moveBefore, используется перенос с сохранением DOM-состояния.
Положение floating-окон ограничено viewport. Раскладка не входит в Undo документа.

Есть вложенные split-деревья sidebar и плавающие группы. Отдельных нативных OS-окон и
сохранения раскладки между запусками пока нет. Это заменяет прежнее ограничение на
отсутствие drag-and-drop docking ниже.

Проверено: сборка и 72 unit-теста (четыре новых теста layout-модели); docking-ui,
panels-ui, layout-ui, brush-ui, commands-ui, scrub-bounds-ui, ui и workflow-ui прошли.
Новые проверки выполняют реальные pointer-жесты. Старые ui-селекторы прямых .sidebar>.panel
обновлены на dock-заголовки; старый swap проверяется через Window, drag-and-drop — отдельно.
Один повтор workflow потребовался из-за короткого нативного scrub-жеста (28 вместо 30).
Снимки `test-results/docking/pinned-detachable-tool-tabs.png`,
`dock-placement-highlight.png` и `unpinned-shared-tab-header.png` просмотрены визуально.
Дополнительно docking-ui проверяет подсветку и маркеры до отпускания, отсутствие подсветки
после drop и неизменность геометрии окна при pin. После унификации сборка, все 72 unit-теста,
docking-ui, panels-ui, layout-ui и brush-ui прошли повторно.

## Всплывающие панели и вкладки

Настройки инструментов теперь немодальные: Settings или ПКМ по холсту/пустой области
viewport открывает их у курсора/кнопки без затемнения. ПКМ в Outliner и меню типов фигур
сохраняют свои действия. Клик снаружи закрывает незакреплённую панель; весь этот жест
поглощается, включая drag/click, чтобы он не рисовал, не двигал объекты и не активировал
кнопку под панелью. Следующий жест работает обычно. Escape / крестик закрывают панель.

Панель перемещается за заголовок, изменяет размер за угол и остаётся в границах окна.
Кнопка с замком закрепляет её: внешний клик больше не закрывает её и не блокирует
рисование. При смене инструмента закреплённая панель показывает его параметры.
Basic / Advanced собраны через общий компонент PanelTabs; переключение вкладок
сохраняет содержимое и поддерживает стрелки / Home / End. Ненужного focus trap нет.

Кнопка-сетка в правом верхнем углу боковой панели объединяет Outliner / Details во
вкладки; повторное нажатие возвращает раздельный вид с разделителем. Это общий
контейнер для React-панелей, а не две независимые реализации. Пока нет произвольного
drag-and-drop docking между группами, отрыва любой вкладки в отдельное окно или
сохранения раскладки между запусками. Основное окно Interface settings пока прежнее.

Проверено: сборка, все 68 unit-тестов, brush-ui, layout-ui, panels-ui, ui и
scrub-bounds-ui. Новый panels-ui проверяет открытие ПКМ, отсутствие backdrop,
поглощение первого внешнего жеста, следующий штрих, pin + рисование, drag заголовка,
отсутствие активации кнопки под закрывающим кликом, вкладки и возврат split-вида.
Первый запуск нового теста остановился из-за неверного имени поля поиска в тесте;
после исправления на существующее Search objects сценарий прошёл. Снимки реального
окна `test-results/panels/pinned-tool-panel.png` и `grouped-sidebar-tabs.png` просмотрены.

## Дублирование, раскладки и настройки инструментов

Ctrl+D / Duplicate создаёт копию рядом в той же иерархии: исходный parentId и локальные
opacity/visible/locked/parentOffset сохраняются, дочерние связи внутри копии получают новые ID.
Смещение дубликата остаётся 20 единиц холста по X/Y даже под повёрнутым/масштабированным
родителем. В заблокированного родителя дубликат не добавляется. Copy/Paste по-прежнему
использует отдельный снимок и вставляет на корневом уровне, сохраняя мировой вид.

Общие команды и выбор инструментов используют физические KeyboardEvent.code: Ctrl+Я
работает как Ctrl+Z, Ctrl+С/М/Ч/В/Ф — как C/V/X/D/A в русской раскладке. Эта же обработка
используется в контекстных меню и для отмены активного перемещения/рисования/числового
перетаскивания. Alt/AltGr не перехватываются; обычный ввод текста остаётся нативным.

Класс Tool задаёт primaryParameters и иконки параметров. На верхней панели отображаются
основные параметры, остальные открываются кнопкой Settings с иконкой. Окно содержит Basic
и Advanced, общие контролы с живым обновлением, изменение размеров, закрытие Escape и
возврат фокуса на кнопку открытия. У кисти сверху только Size / Color / Opacity / Tip.
Настройки хранятся в текущем сеансе; постоянного сохранения пресетов пока нет.

Проверено: сборка, 68 unit-тестов; layout-ui, brush-ui, commands-ui, scrub-bounds-ui,
tools-ui и workflow-ui. Русские сочетания в UI проверяются событиями key+code, без смены
системной раскладки ОС. Снимки: test-results/layout/.

## Выбор дочернего объекта на холсте

После перехода от родителя к дочернему повторным кликом выбор остаётся на дочернем:
небольшое смещение курсора и последующие перетаскивания не возвращают выбор к родителю.
Движение завершает только последовательность углубления кликами, но не текущий уровень
редактирования. Явно выбранный в Outliner дочерний объект также сразу можно перемещать.
Клик по другой ветке по-прежнему начинает выбор с её родителя; последовательные клики
без движения позволяют углубляться дальше. Проверено: сборка, 66 unit-тестов,
workflow-ui (включая два последовательных drag после входа в дочерний) и inheritance-ui.

## Обновлённая кисть

Тип наконечника: Round (круглый), Soft (мягкий), Flat (плоский). Параметры:
Hardness — жёсткость, Flow — накопление краски за отпечаток, Opacity — прозрачность
штриха, Spacing — шаг в долях диаметра, Roundness — сплющивание, Tip angle — угол.
Stabilizer: Off / Smooth / Pulled string; Smoothing задаёт силу стабилизации.
Pen pressure → Size включает размер от давления пера; мышь использует полный размер.
Физический планшет пока не проверен. На отпускании указателя штрих догоняет курсор.

Параметры появляются из общего Tool-класса. Каждый штрих хранит собственные настройки,
старые штрихи не меняются; рисование работает на выбранном незаблокированном слое,
Undo/Redo и Escape сохранены. Панель переносит параметры на следующие строки.
Это SVG-реализация, без импорта ABR и без переноса всего Rust paint-движка.
Исследование исходников, commit SHA, лицензии, решения и ограничения:
[docs/brush-research.md](docs/brush-research.md).
Сборка, 65 unit-тестов и четыре UI-сценария (brush, workflow, tools, commands) прошли.

## Проверка

Повторная сборка на Windows: `scripts/copy-asset.mjs` пропускает неизменившиеся ресурсы и снимает ReadOnly только с обновляемых сгенерированных копий. Исходные ресурсы не меняются; регрессионный тест проверяет первую/повторную сборку и обновление readonly-копии. `pnpm test` — 5 тестов модели/сборки. Для отдельного каталога снимков UI-теста можно задать `MYCUT_UI_RESULTS`.

Проверено на Windows: сборка, 4 теста модели, Electron/Playwright-сценарий выбора/живого ввода/Undo/Redo/Escape/видимости/поиска/текста/перемещения/разделителей/перестановки панелей/UI scale/добавления и малого окна; renderer без Node. Снимки — реальное окно Electron, не браузерный макет. Найден и исправлен случай запуска с завершающим слэшем Windows-пути: аргумент нормализуется через `path.resolve`, launcher передаёт явный `main.cjs`.

`pnpm test` — модель; `pnpm test:ui` — настоящий Electron через Playwright, pointer/keyboard-сценарии и снимки `test-results/`. `pnpm build` — сборка. При отсутствии системного Node используйте предоставленный runtime. Roboto берётся из существующих `next/app/assets/fonts` вместе с LICENSE/NOTICE; ресурсы Epic не копируются.

Renderer: sandbox, contextIsolation, без Node, с узким IPC только для диалогов и файлов MyCut-проекта. CSP запрещает сеть; навигация, popup и запросы разрешений заблокированы. Это SVG-прототип, не wgpu: уже есть docking, ограниченный DAG эффектов, импорт/экспорт и сохранение проекта, но нет GPU-обработки фото и редакторного 3D. Исторические проверки выше отражают состояние соответствующего этапа.

Формы объединены в Shapes: Rectangle, Ellipse, Line, Arrow, Triangle, Diamond,
Pentagon, Hexagon, Star, Polygon, Heart, Callout выбираются в списке Shape.
Первый клик выделяет фигуру, повторный клик по выделенной открывает Edit, в том
числе для фигуры-источника NodeInput. Линия/стрелка редактируются за концы
(Shift — шаг угла 15°), многоугольники/звезда — за вершины, Heart — за контроль
долей, Callout — за хвост. Escape отменяет жест, Undo/Redo и файл проекта
сохраняют геометрию.

Отдельные инструменты: Eyedropper (C), Gradient (G), Crop (K), Rectangular
selection (M), Bucket fill (F), Magic wand (W). Заливка и градиент работают
на выбранном видимом незаблокированном слое, учитывая пиксельное выделение.
Wand/Fill поддерживают допуск цвета и связную область либо все совпадения.
Выделение: Replace/Add/Subtract/Intersect, Shift добавляет, Alt вычитает,
Escape снимает. Выделение ограничивает заливку, градиент, ретушь, кисть и ластик.
Crop — неразрушающая обрезка выбранного слоя, не всего документа.
Пиксельные операции — CPU/SVG-прототип: документ 960×600, локальный bitmap
до 2048 px по стороне; это не полная реализация Photoshop.
Проверки: tests/functional-tools-ui.mjs, tests/shape-picking-ui.mjs,
tests/vector-tools-ui.mjs и unit-тесты tests/pixel-regions.test.mjs.

Дополнительно доступны 10 инструментов: Blur brush, Sharpen brush, Smudge,
Dodge, Burn, Sponge (Saturate/Desaturate), Clone stamp, Healing brush, Liquify
и Lasso. У кистей есть Size/Strength; Clone/Heal сначала требуют Alt-клик
источника на выбранном слое. Обработка выполняется при отпускании мыши,
с учётом пиксельного выделения. Сохраняются траектория и параметры ноды
RasterEffect; изменение силы, размера, концов траектории или входа ноды
пересчитывает результат. Bitmap хранится как предварительный просмотр,
а не замена исходного объекта. Поддерживаются Undo/Redo и проектный файл.
Smudge — протягивание цвета начальной точки, Heal — перенос текстуры с
локальной компенсацией тона, Liquify — кистевое смещение пикселей; это
базовые CPU-версии, не полнофункциональные инструменты Photoshop.

В контекстном меню графа добавлены 30 нод:

- Blur, DirectionalBlur, Sharpen, UnsharpMask, Emboss, EdgeDetect.
- Brightness, Contrast, Saturation, HueRotate, Grayscale, Sepia, Invert,
  Exposure, Gamma, Threshold, Posterize, Colorize, Temperature, Tint.
- Opacity, AlphaThreshold, Dilate, Erode.
- DropShadow, InnerShadow, Glow, Offset, Displace, Turbulence.

У них один вход base; Displace использует внутренний шум с Frequency/Seed.
Подключите Input → фильтр → Output, выберите ноду и меняйте параметры в
Details. Все параметры проверяются при чтении проекта. Фильтры реализованы
SVG-примитивами по [спецификации W3C](https://www.w3.org/TR/SVG11/filters.html).
Списки форм в меню Shapes и панели параметров сначала показывают пять форм,
остальные раскрываются через «Другие формы…».
Новые проверки: tests/filter-retouch.test.mjs и tests/advanced-tools-ui.mjs
(все 30 фильтров подключаются по очереди с проверкой изменения пикселей).

Текущая модель инструментальных эффектов:

- Gradient — генератор с 1–32 цветовыми точками (позиция/цвет/прозрачность).
  На пустом Layer он заполняет композицию; на объекте подключается через
  ConvertToAlphaMask → AlphaMultiply. В Edit доступны концы градиента.
- Crop — RectangleMask × вход объекта, с восемью ручками и перемещением рамки.
  Градиент, обрезка, заливка, ретушь и рисование имеют режимы Create/Edit.
  При открытии старый cropRect переводится в ноды, если позволяет лимит графа.
  Старые растровые градиенты остаются картинками: их утраченные точки восстановить нельзя.
- Fill — SolidColor × BitmapMask, сложенный с входом; цвет остаётся редактируемым.
- Мазки Brush/Eraser автоматически объединяются в маску соответствующего канала.
  Через меню графа можно создать PaintMaskNode; пока она выделена, рисование
  редактирует именно её. Маски выделения сохраняются в координатах объекта.
- Выделение области следует за объектом. Ctrl+C/X копирует/вырезает только её
  пиксели, Ctrl+V создаёт независимый Image-слой. Средняя кнопка и Space+drag
  панорамируют при любом инструменте.
- Имя объекта, Enabled и основные параметры видны на карточках нод;
  All parameters раскрывает остальные. Фон графа бескрайний визуально.
  Замок графа/ноды Input включён по умолчанию; выключенный граф следует Outliner.
  Удаление промежуточного эффекта переподключает потребителей к его base-входу.
  Alt-клик разрывает провод. Порты имеют адаптивные области захвата и Enter-доступ.
