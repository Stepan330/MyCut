# MyCut — запускаемый прототип окна отсмотра

## Как запустить

1. Распакуй архив полностью, например в D:\Приложение для пк\MyCut_v1.
2. Внутри папки MyCut_Windows_Preview дважды нажми Start-MyCut.cmd.
3. Откроется отдельное окно MyCut. Уже включены демонстрационное видео, фото и аудио.
4. Нажми Import files или перетащи свои файлы в окно.

Предназначен для Windows 10/11 с Windows PowerShell 5.1 и WPF/.NET Framework. Python, Node, установка пакетов и доступ в интернет не нужны. На Windows N без мультимедийных компонентов воспроизведение может быть недоступно.

## Что можно проверить

- Отдельное окно приложения с интерфейсом на английском.
- Импорт видео, фото и аудио; категории, поиск, карточки и список.
- Просмотр настоящего локального видео, воспроизведение и перемотка.
- Наведение на карточку видео: через небольшую задержку появляется беззвучный предпросмотр.
- Анимация карточки при наведении.
- Просмотр фото и увеличение.
- Метки, начало/конец выбранного участка, повтор участка.
- Несколько сохранённых фрагментов одного исходника.
- Избранное, заметки, изменяемые размеры панелей.
- Save collection / Open collection.
- Подборка автоматически сохраняется при обычном закрытии и открывается при следующем запуске.

Оригинальные файлы не меняются. Подборка хранит ссылки на них.
Автосохранение находится в %LOCALAPPDATA%\MyCut\ReviewPreview\collection.json.
Файл collection.json можно удалить вручную, если хочешь снова начать с демонстрационной подборки.

## Клавиши

Space — пуск/пауза. I/O — начало/конец участка. M — метка.
Стрелки влево/вправо — приблизительный шаг 40 ms; это ещё не точное декодирование отдельного кадра.
Home/End — начало/конец исходника.
В поле времени вводи 00:00:09.300 и нажимай Enter.

## Что это за версия

Это временный прототип интерфейса на стандартных компонентах Windows, чтобы обсудить расположение и поведение элементов на твоём ПК.
Собственный MyCut Runtime, нодовый редактор интерфейса, общий GPU-движок, монтаж и фоторедактор в этой версии ещё не реализованы.
Поддержка видео зависит от мультимедийных компонентов и кодеков Windows; FFmpeg пока не встроен.
Настоящие миниатюры видео и звуковая волна пока не рассчитываются. Фото имеют превью.
Анимация карточек реализована средствами WPF; это не измерение производительности будущего MyCut Runtime.

Прототип запускается через Start-MyCut.cmd. Это ещё не установщик и не собранный MyCut.exe.
Исходники включены в архив: MyCut.ps1 и MainWindow.xaml. Они пригодны для дальнейшего размещения в GitHub.

## Если не открылось

В папке программы появится mycut-startup.log или mycut-console.log. Пришли текст ошибки из этого файла.
Если открылось окно, но конкретное видео не играет, попробуй включённый Demo_Motion.mp4 или другой MP4 H.264.

## Что прислать для следующей правки

Скрин окна и конкретные замечания: какую панель увеличить, куда переместить кнопки, как должен работать выбор клипа и наведение.

## Проверка сборки

Структура XAML, имена элементов, упаковка, демонстрационные медиа и базовая логика сохранения проверяются при подготовке архива.
Запуск Windows/WPF в текущей среде не доступен; реальный запуск и декодирование на Windows ещё нужно проверить на твоём ПК.
