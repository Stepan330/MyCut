# MyCut — первое окно «Отсмотр материала»

13 октября 2026 года. Набросок для обсуждения, до реализации приложения Windows.

## Цель

Быстро открыть подборку, понять содержимое исходников, найти удачные моменты и сохранить их для последующей работы. Окно пригодно для самостоятельного отсмотра без монтажного проекта.

Текущий результат — интерактивный набросок интерфейса с демонстрационными материалами. Это не Windows-приложение и не готовый медиадвижок. Остальные редакторы представлены только неактивными пунктами навигации.

## Что изучено в программах-референсах

### FL Studio: Playlist

Официальное руководство описывает горизонтальный масштаб вокруг курсора, Ctrl + колесо, приближение выделения, обзор всего проекта, перемещение воспроизводящей позиции, маркеры и обзорный горизонтальный ползунок.

Для MyCut предлагаются похожие принципы навигации, но шкала отсмотра показывает время исходника в секундах. Музыкальные такты и дорожки Playlist не переносятся в окно отсмотра.

Источник: [Image-Line — The Playlist](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/playlist.htm).

### DaVinci Resolve: Media и Source Viewer

Официальное описание Media разделяет импорт и организацию материалов, просмотр исходника и его метаданные. Описаны bins, теги и организация по метаданным.

Официальное описание Edit объясняет отметки In/Out в исходнике, клавиши I/O и визуальную звуковую волну для поиска речи и нужных моментов.

В MyCut используем медиатеку, один просмотр исходника, сведения и отбор нескольких фрагментов. Организация подборки не должна менять расположение оригиналов на диске.

Источники: [Blackmagic — Media](https://www.blackmagicdesign.com/products/davinciresolve/media), [Blackmagic — Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit).

Этот разбор основан на официальных руководствах и описаниях. Он не является результатом запуска FL Studio и Resolve на компьютере пользователя.

## Предложенное расположение

Целевая среда — обычное окно Windows на широком экране. Основная область просмотра занимает большую часть ширины.

- Верх: имя приложения, текущая подборка, импорт и переключение редакторов.
- Слева: медиатека и подборки — все материалы, видео, фото, аудио, избранное, материалы с сохранёнными фрагментами.
- Центр: один просмотр выбранного исходника, транспорт и его временная шкала.
- Справа: сведения, заметка и отобранные фрагменты выбранного исходника. Панель можно скрыть.
- Снизу: материалы подборки в миниатюрах или списке; поиск и сортировка.
- Нижняя строка: состояние и короткие подсказки сочетаний.

Предлагаемые разделители панелей для приложения Windows — изменяемые мышью. В текущем наброске показано расположение, но перетаскивание разделителей не реализовано.

## Основной сценарий

1. Открыть окно отсмотра или существующую подборку.
2. Перетащить файлы/папку или нажать «Импорт».
3. Материалы появляются сразу; метаданные, миниатюры и звуковая волна рассчитываются в фоне.
4. Один клик выбирает и открывает исходник. Проигрывание не запускается неожиданно.
5. Переместить позицию по шкале, включить просмотр, приблизить интересующее место.
6. Отметить начало I и конец O, при желании включить повтор выделения.
7. Назвать и сохранить фрагмент.
8. Продолжить отсмотр того же файла и сохранить ещё один фрагмент.
9. Использовать отобранные ссылки в будущем монтажном окне.

Последний шаг определяет связь редакторов. Монтажные дорожки и монтажные операции сейчас не проектируются подробно.

## Поведение разных материалов

| Материал | Просмотр | Шкала времени | Результат отсмотра |
| --- | --- | --- | --- |
| Видео | Кадр, звук, движение | Миниатюры, звуковая волна, отметки | Фрагменты, маркеры, заметка, избранное |
| Аудио | Звуковая волна и воспроизведение | Время и звуковая волна | Фрагменты, маркеры, заметка, избранное |
| Фото | Изображение с масштабом/вписыванием | Скрыта | Заметка, избранное, переход к фоторедактору |

Обработка фото открывается отдельно в Item Редакторе. Создание анимационных кривых — в самостоятельном аниматоре. Окно отсмотра сохраняет исходное содержимое.

## Время исходника

Одна шкала показывает один выбранный исходник. Она не является общим монтажным таймлайном.

- Щелчок или перетаскивание перемещает текущую позицию.
- Ctrl + колесо меняет масштаб вокруг курсора.
- Прокрутка без Ctrl перемещает видимый диапазон.
- Обзорная полоса показывает положение видимого диапазона внутри полного исходника.
- «Весь исходник» возвращает полный диапазон.
- «Выделение» приближает текущий диапазон.
- Кнопки и стрелки перемещают на кадр.
- I/O задают начало и конец текущего выделения; границы также можно перетаскивать.
- Метки принадлежат исходнику, а не будущему монтажному размещению.

В приложении Windows точное время хранится в рациональном представлении/исходных timestamps. Для видео с переменной частотой кадров покадровая навигация использует реальные timestamps кадров. Десятичные секунды в наброске — упрощение интерфейса.

Граница Out трактуется как исключающая: начало включено, конец обозначает первый момент за выбранным участком. Нулевая или обратная длительность не сохраняется.

## Предлагаемые сочетания

| Действие | Сочетание | Текущий набросок |
| --- | --- | --- |
| Пуск / пауза | Space | Есть |
| Начало / конец | I / O | Есть |
| Метка | M | Есть |
| Предыдущий / следующий кадр | Стрелки влево / вправо | Есть, упрощённый шаг |
| Начало / конец исходника | Home / End | Есть |
| Масштаб вокруг курсора | Ctrl + колесо | Есть |
| Сохранить выделение | Предлагается отдельная команда с переназначением | Только кнопка |
| Обратный/ускоренный просмотр | J / K / L как кандидат | Позже |

Сочетания не срабатывают при вводе текста. Для Windows предусмотрены переназначение и независимость команд от русской/английской раскладки. Текущий браузерный набросок использует латинские I/O/M.

## Сохранённые фрагменты

Фрагмент содержит стабильный идентификатор, ссылку на исходник, начало, конец, название и необязательные заметки.

Сохранение фрагмента не создаёт новый видеофайл. Один исходник может иметь любое число независимых фрагментов. Открытие фрагмента восстанавливает границы и позицию. Удаление фрагмента из отбора не удаляет исходник.

При дальнейшем изменении границ монтажного размещения другие фрагменты и исходник не меняются неявно. Поведение обновления связанного отбора будет определено при проектировании монтажного окна.

## Данные окна и связь с ядром

Предлагаемые сущности:
- MediaCollection: подборка и организация материалов.
- SourceAsset: ссылка на файл, свойства и состояние доступности.
- ReviewState: позиция просмотра, заметка, избранное, маркеры.
- SelectedRange: сохранённый участок исходника.
- ViewerSession: текущее воспроизведение и навигационный масштаб.

MediaCollection сохраняется самостоятельно и может подключаться к видеопроекту. Монтаж получает ссылки SourceAsset/SelectedRange; фоторедактор получает SourceAsset для создания PhotoDocument. Кэш миниатюр и волн не является авторским содержимым подборки.

Подборка требует собственного сохранения и восстановления. В интерактивном наброске состояние сохраняется только пока открыт просмотр; автосохранение, файл проекта и перенос в папку Windows не реализованы.

## Состояния для первой реализации

- Пустая подборка: импорт или перетаскивание.
- Чтение файла: видимый статус, остальные файлы доступны.
- Недоступный исходник: сохранённые метки остаются; команда поиска перемещённого файла.
- Неподдерживаемый формат: сообщение с именем файла; остальные материалы продолжают работать.
- Фоновое создание миниатюр/волны: просмотр имеет приоритет.
- Нет звука: это явно видно; не отображается вымышленная звуковая волна.
- Фото: шкала времени и сохранение временного фрагмента скрываются.
- Переключение исходника: воспроизведение предыдущего останавливается.

## Что работает в наброске

Выбор демонстрационного исходника, движение позиции, пуск/пауза демонстрационного времени, I/O, перетаскивание границ, сохранение и удаление ссылок-фрагментов, маркеры, повтор, масштаб, поиск, фильтрация, избранное, заметки, список/миниатюры и скрытие панели сведений.

Можно открыть локальное фото, видео или аудио, если браузер понимает формат. Файлы остаются локальными. Метаданные реального видео ограничены возможностями браузера; FPS и настоящие миниатюры/волны не вычисляются. Демонстрационные кадры и волны подписаны как демонстрационные.

Масштабирование фото, сохранение подборки, J/K/L, редактирование маркеров, перемещение панелей и переход к другим редакторам остаются планом.

Проверка наброска: синтаксис JavaScript и сценарии выбора, воспроизведения времени, I/O, сохранения/восстановления фрагмента, масштаба, поиска, фоторежима, скрытия сведений и некорректного диапазона проверены в событийной модели DOM. Полноценная визуальная проверка в браузере этой среды не выполнена: установленная автоматизация не имеет исполняемого браузера. Это ограничение проверки наброска, а не требование к приложению Windows.

## Порядок разработки после правок

1. Уточнить расположение панелей и поведение кликов по материалам.
2. Реализовать импорт, ссылки на исходники и сохранение подборки.
3. Реализовать настоящий просмотр, синхронизацию звука и точную покадровую навигацию.
4. Добавить фоновые миниатюры, волну и лимиты кэша.
5. Реализовать маркеры, несколько фрагментов и их сохранение.
6. Добавить переназначаемые команды, восстановление отсутствующих файлов и настройку панелей.
7. Собрать первую Windows-версию отсмотра и установщик.
