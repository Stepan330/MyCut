# Проверка интерфейса MyCut Next — 16.10.2026

Область: Rust photo slice. Проверены реальные GPU-снимки браузера, настроек и ввода текста; поведение — event tests egui. Это эвристическая проверка разработчиком, не пользовательское исследование и не сертификация доступности.

Последующая архитектурная доводка: [UI Core/docking](UI_COMPONENTS.md). Панели теперь закрепляются по краям/во вкладки, настраиваются отдельно, раскладка сохраняется. Fit исправлен под реальную область канваса и пропускает предварительную геометрию запуска native окна. Проверены новые GPU-снимки docking-check/docked-left-check/panel-settings-check; исходный аудит ниже сохранён как история.

## Основания

- [Nielsen Norman Group: usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/): последовательность, обратная связь, отмена действий, отсутствие лишнего шума.
- [W3C: contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): ориентир 4.5:1 для обычного текста.
- [W3C: target size minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum): ориентир 24×24 с предусмотренными стандартом исключениями. Для native UI используется как полезная рекомендация, не заявление о WCAG-conformance.

## Результат и исправления

| Проверка | Наблюдение и действие |
|---|---|
| Иерархия | Единые заголовки и сворачиваемые группы; Scale и Position выше Rotation; Flip отдельно двумя иконками. |
| Плотность | Убраны крупные карточки параметров; компактная сетка, связанный X/Y, общие колонки. Details и Outliner разделяются изменяемой границей. |
| Подписи ресурсов | Пропорциональный preview, имя до двух строк с многоточием, полный tooltip, отдельный тип и цветовая полоска. Тип читается текстом, не только цветом. |
| Папки | Одинаковые векторные иконки рядом с названиями, отступы и стрелки. Дерево файлов показывает текущую ветку и дочерние папки, а не всю файловую систему. |
| Обрезание | На первоначальном снимке тип карточки требовал прокрутки. Начальная высота браузера увеличена 230→270 DIP; при уменьшении остаётся прокрутка. Минимум Inspector 300 DIP защищает строки Transform от обрезания. |
| Попадание | Компактные action-кнопки увеличены 20→24 DIP; основные 27 DIP. Адаптивные зоны манипуляторов сохраняются. Числовые поля остаются компактными; полная touch-проверка не выполнена. |
| Контраст | Вторичные подписи усилены до #BEBEBE; тест проверяет минимум 4.5:1 на фоне панели и выделенной карточки. Это не аудит всех состояний и цветов. |
| Иконки | Общий code-native набор без зависимости от символов системного шрифта; действия имеют tooltip и semantic label. Недоступные функции не изображаются рабочими кнопками. |
| Обратная связь | Preview обновляется без следующего движения мыши; выбранный слой синхронизирован в трёх представлениях; ручки и кольцо показывают активное действие. |
| Движение | Анимации короткие, сила настраивается до 0; расширение и затухание зон плавные. Не добавлены декоративные 3D-эффекты, мешающие редактированию. |
| Контроль пользователя | Undo на жест, Escape для отмены, подтверждение несохранённого документа; отдельные масштабы UI и канваса. |

## Открытые ограничения

Global сейчас показывает один документ, не будущую систему Prefab/композиций. Текстовый overlay при вводе не повторяет произвольный поворот. Нет полной проверки клавиатурной навигации, screen reader, IME, маленьких экранов при максимальном UI zoom, touch и нескольких мониторов. Native file dialogs не стилизованы как внутренние панели. Следующий дизайн-проход должен включать реальные пользовательские сценарии и эти размеры/режимы; заявлять, что соблюдены «все правила дизайна», нельзя.
