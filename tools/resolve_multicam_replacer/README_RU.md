# Resolve Multicam Replacer

Инструмент заменяет уже нарезанные видеофрагменты на одной дорожке непрерывным
Multicam Clip. Позиции склеек и пропусков берутся с таймлайна. Исходный таймлайн
никогда не редактируется: при применении создаётся копия.

## Перед запуском

1. Откройте нужный таймлайн в DaVinci Resolve.
2. В **Media Pool** выберите ровно один подготовленный Multicam Clip.
3. Укажите одну видео- и одну аудиодорожку, которые были синхронны до монтажа.
4. Убедитесь, что первый кадр Multicam соответствует началу первого фрагмента на
   обрабатываемой видеодорожке. Если нет, задайте `Multicam In первого клипа`.
5. В Resolve откройте **Preferences → System → General → External scripting using**
   и разрешите локальные сценарии, если доступ к API ранее был отключён.

Запустите `Start-Resolve-Multicam-Replacer.cmd`, укажите номер дорожки и нажмите
**Проверить**. Сначала программа только покажет рассчитанные диапазоны. Кнопка
**Создать копию и заменить** всегда дублирует текущий таймлайн.

Для portable-версии укажите в поле **Portable Resolve.exe** фактический исполняемый
файл сборки. Программа проверит наличие `fusionscript.dll` рядом с ним. Если этой
библиотеки в portable-сборке нет, внешний Scripting API использовать невозможно:
нужна полная установка Resolve либо portable-сборка, содержащая Developer/Scripting
и `fusionscript.dll` со всеми зависимостями.

Проверка native API запускается в изолированном процессе. Несовместимая DLL больше
не должна закрывать главное окно. Общий журнал аварийного запуска сохраняется в
`last-run.log` рядом с программой.

Программа использует Source Start клипов и перекрытия выбранных видео/аудиодорожек.
Так непрерывное аудио переносит время через смену видеофайла, а непрерывное видео —
через смену аудиофайла. Обычные монтажные вырезы не считаются временем записи.

## Как выполняется замена

Для каждого фрагмента программа добавляет Multicam Clip как новый **Take** с
нужными source In/Out и выбирает этот take. Она не удаляет клипы и не делает ripple
delete, поэтому позиции монтажа и связанный звук остаются на месте. Фрагменты,
выходящие за диапазон Multicam, заранее помечаются `SKIP`. Если Resolve отклонит
часть операций, копия таймлайна получает суффикс `[CHECK ERRORS]`.

Ограничение: это первая безопасная версия. Перед удалением исходного таймлайна
визуально проверьте несколько склеек, синхрон в начале/середине/конце и атрибуты
клипов, особенно если на них были retime-эффекты или speed ramps.
