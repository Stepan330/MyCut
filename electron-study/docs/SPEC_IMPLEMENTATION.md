# Внедрение MASTER SPEC v0.3

Рабочая карта, 21 октября 2026. Спецификация задаёт направление; статус ниже не означает, что весь будущий продукт готов.

## Граница безопасности

Новые правила взаимодействия и совместимые возможности внедряются в редактор. Системы, меняющие модель исполнения или документа, сначала проверяются в **Architecture Lab**. Лаборатория имеет собственные данные, историю, часы и runtime; закрытие не меняет проект. Старые документы не мигрируются молча в новый мир.

## Не переносить в ядро без проверки

Групповая post-composite opacity, новый формат документов, Prefab и ресурсы, произвольный canvas, Screen Color / Composite Output, контейнерный layout, глобальные bindings и единый render scheduler требуют отдельных интеграционных этапов. Прототипы не являются заменой текущему renderer. Формат основного проекта остаётся v1 с совместимыми дополнительными полями/нодами.

## Что ещё не сделано

- Не перенесены основные панели/кнопки редактора в Interface World. Старые CSS-анимации не объявляются полноценными материальными Living-графами.
- Нет полноценного Prefab/Effect Definition Content Browser, Apply/Revert/Unpack, reimport/relink/collect project и cross-project dependency collection. Definitions в Lab — работающий вертикальный прототип, не библиотека ресурсов продакшен-формата.
- Нет многоконтурного слоя, полной системы Controllers/Anchors/Pivot/Edit Handle, общего SnapEngine с дизайнерскими сетками/направляющими/гистерезисом.
- Не введён полный глобальный стек редактирования для всех панелей; основной progressive unwind работает на канвасе и через Esc.
- Нет единого Command Registry для каждой существующей операции редактора, полноценного Intent Engine, всех workspace presets/monitor persistence и общей Navigation History основного интерфейса. Эти контракты пока проверяются в Lab.
- Geometry не выдаёт векторные anchors/baselines; UI graph editor лаборатории позволяет менять параметры и переподключать типизированные входы существующих нод, но пока не добавляет произвольные ноды и не заменяет полный интерактивный Node Graph всех будущих UI-поведений.
- Нет полноценного художественного Animation Editor, Glyph Map после layout текста, Timeline/Video/Audio/3D, GPU residency/fusion, мультимедиа scheduler или 4K performance benchmark.

Нельзя считать эти пункты выполненными по наличию общих типов и тестовых окон.

## Как проверять

1. Собрать редактор обычной командой build/start.
2. `Window → Architecture Lab` или `Ctrl+K → Architecture Lab`.
3. Living UI: выбрать стихию, приблизить указатель, изменить направление движения, перенести панель мышью, проверить Undo/Redo и Esc, Lift/Press, закрыть тело, проверить остаток и Safe UI.
4. Earth: дождаться процедурной фактуры, изменить Seed, раскрыть Stone material graph, проверить диффузную пыль по всему контуру.
5. Animation: изменить Strength из двух представлений, переключить 0.250 → 1.750 → 0.250, добавить keyframe, Undo.
6. Canvas & Glass: сравнить Layer/Composite, изменить размеры в трёх режимах, переместить стекло, Undo.
7. Definitions: изменить определение, сделать override, подключить общий Global blur, отвязать, Make Unique; проверить цикл ресурсов.
8. Основной граф: выбрать Output, увидеть три порта и диагностику; добавить Fractal noise через обычный поиск нод.

Сборка и unit-тесты проходят. Electron-тесты покрывают лабораторию/изоляцию проекта, шумовые генераторы, отдельные Output-каналы, выделение, эффекты/параметры/подсветку, динамические маски/ручки, снап, docking, создание/удаление дочерних объектов и сохранение. Снимки находятся в test-results (не включаются в исходники).

Спецификация сама относит полный Video Editor, realtime audio, 3D, shader fusion и детальную систему кистей к последующим этапам. Их нельзя объявлять готовыми по наличию схемы данных.
