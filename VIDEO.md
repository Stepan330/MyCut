# MyCut 0.7 — Video

Нажать **Video** в компактной верхней строке. Главный canvas становится program preview, под ним появляется компактный таймлайн; его не перекрывает отдельное окно. **Media / clip controls** открывает перемещаемую и изменяемую панель медиабина, свойств клипа и экспорта. **Photo** возвращает статическую композицию и всё пространство canvas. Закрытие панели останавливает транспорт, но оставляет выбранный video workspace.

## Рабочий сценарий

1. Import media: PNG/JPEG/BMP/TIFF или видео, поддерживаемое установленными Windows Media Foundation codecs. Проверены H.264 MP4; расширение файла само по себе не гарантирует поддержку codec.
2. Выбрать источник в медиабине, поставить playhead и нажать Insert at playhead. Либо перетащить источник на дорожку. Статическое изображение/генератор первоначально занимает 5 секунд, видео — доступную длительность источника.
3. + Track создаёт верхнюю дорожку. Более высокие дорожки накладываются поверх нижних. Клик по имени выбирает дорожку; M выключает её изображение, L блокирует монтаж.
4. Перетаскивать середину клипа для перемещения во времени/между незаблокированными дорожками. Края имеют широкую, направленно расширяющуюся зону захвата; ближайший нормализованный edge выигрывает конфликт. Рост/притяжение ручки не меняет координаты клипа.
5. Потянуть край для обрезки: противоположная граница остаётся неподвижной, левая обрезка меняет Source In. Видеоклип не растягивается за доступный источник. Поля Start, Duration, Source In, Speed и Fade In/Out поддерживают drag и точный ввод, группируя жест в один Undo.
6. S / Split разрезает клип в playhead, Delete удаляет его, Shift+Delete / Ripple delete также сдвигает следующие клипы той же дорожки. Escape откатывает текущий drag.
7. Space / Play, стрелки или кнопки Frame перемещают playhead. Время транспорта считается от монотонных часов, а не от числа UI ticks. Preview допускает пропуск кадров при недостаточной скорости декодирования, export ожидает нужный кадр.
8. I / Set In и O / Set Out задают диапазон вручную; Out — исключённая правая граница (Set Out включает текущий кадр). Выбор/обрезка клипа не изменяют диапазон. При unset Out экспорт заканчивается на конце последнего клипа.
9. Export MP4: чистый 1280 × 720 H.264, 12 Mbps, project FPS. Экспорт работает на отдельном immutable snapshot; документ можно продолжать редактировать. Cancel действует между кадрами и удаляет только собственный уникальный `.partial.mp4`. Существующий файл заменяется лишь после успешной финализации.

Средняя кнопка / wheel — горизонтальная прокрутка, Ctrl+wheel — масштаб вокруг курсора, Shift+wheel — дорожки. Alt временно отключает привязку к нулю, playhead и краям других клипов. При drag у границы начинается автопрокрутка. Fit clips — только навигация, не In/Out.

Ось начинается с нуля и не ограничивается длительностью контента; предохранительный предел — 1 млрд кадров. Временная модель — int64 frames + rational FPS. UI текущей версии использует 30 fps; ядро и формат уже сохраняют дробную rate, но выбор project FPS в UI ещё не добавлен. Display time показывает прошедшие миллисекунды, не SMPTE drop-frame timecode.

## Модель и обработка

Track/Clip и media timing сохраняются в `.mycut` v5. Клип владеет отдельным Instance с независимыми transform/ColorGrade и ссылается на shared Definition источника. Исходник остаётся в медиабине. Clip instances не добавляются повторно в статическую photo composition.

Media Foundation Source Reader декодирует RGB32 в отдельном MTA worker. Обычный viewport не ждёт декодер, показывает последний доступный кадр и повторно рисует pending результат. Scopes, PNG и MP4 получают точный кадр синхронным ожиданием своего независимого renderer. У каждого активного video instance — bounded cache до 8 кадров / 64 MiB. При исчезновении video plane из активного кадра его worker/cache освобождаются. GPU texture budget остаётся 256 MiB.

Физическая аналогия: клипы — полоски плёнки на монтажном столе; края — широкие захваты, которые выдвигаются к руке; привязка — слабый магнит у соседней границы. Линейка остаётся неподвижной системой измерения, а spring-анимация захвата не растягивает время документа.

## Явные ограничения

Звуковая дорожка/микшер/синхронизация аудио, thumbnails/waveforms на клипах, переходы кроме opacity fades, keyframes, proxy/relink, выбор project resolution/FPS, ICC/HDR, специализированный VFR workflow и device-loss recovery ещё не реализованы. Media source остаётся внешним абсолютным путём. Экспорт ограничен 10 млн кадров на одну задачу. Эта версия не заявляется полноценной копией Resolve или Blender.
